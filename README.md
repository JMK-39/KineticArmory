# KineticArmory

## English

KineticArmory turns existing equipment into configurable sets with bonuses triggered by worn pieces, conditions, and combat events.

### Choose which mobs can match an equipment set

Turn on this set’s entity whitelist, find a cow and a pig, and click their preview cards. Save the filter to the set draft and reopen it to check both choices.

![Enabling an equipment set’s whitelist and selecting cow and pig preview cards, then reopening the saved filter](https://raw.githubusercontent.com/wiki/JMK-39/KineticArmory/media/tutorials-20261126/en.gif)

[Editor guide](https://github.com/JMK-39/KineticArmory/wiki/Entities-and-Tooltips)

- Visual set, equipment-variant, and condition editors.
- Attributes, potion effects, damage rules, flight, and commands.
- Curios equipment, configurable tooltips, and optional KubeJS events.

Supports Minecraft **1.20.1 / Forge 47.4.2+** with **Java 17**, **1.21.1 / NeoForge 21.1+** (validated with 21.1.252) with **Java 21**, and **26.1.2 / NeoForge 26.1.2.0+** (validated with 26.1.2.112) with **Java 25**. Requires **KineticCore 26.11.24+** matching the Minecraft/loader. Install required mods on the server and connecting clients.

Required: Curios 5.10+ on Forge 1.20.1, 9.x on NeoForge 1.21.1, or 15+ on NeoForge 26.1.2. Optional: KubeJS 2001.6.5+ on Forge 1.20.1 or 2101.x on NeoForge 1.21.1 (the KubeJS build for 26.1 does not start on 26.1.2 yet).

## 简体中文

KineticArmory 将已有装备组成可配置套装，让加成随穿戴件数、条件和战斗事件变化。

### 用实体卡片设置套装适用对象

打开套装的实体白名单，搜索牛和猪，再点击对应的模型卡片。把筛选规则保存到套装草稿，返回并重新打开，核对两项选择。

![启用套装实体白名单，点选牛和猪的模型卡片，再重新打开筛选核对的实录](https://raw.githubusercontent.com/wiki/JMK-39/KineticArmory/media/tutorials-20261126/zh.gif)
