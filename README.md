# KineticArmory

> V1.0

## 简体中文

通过可视化配置创建装备套装及其动态加成。

### 核心功能

- 创建、复制和编辑套装，支持普通装备槽与 Curios 饰品槽。
- 按穿戴件数、装备变种、NBT 和组合条件激活不同奖励。
- 设置属性、药水效果、伤害、免疫及命令等套装行为。
- 支持符合规则的非玩家实体，并自动生成套装 Tooltip。

### 使用

按 **F6** 进入 KineticArmory 套装编辑器。服务器负责判定套装是否生效；修改公共套装配置需要管理权限。

### 前置依赖

必需：Forge 47.4.2+、KineticCore 26.9.20+、Curios 5.10.0+；可选：KubeJS 2001.6.5+。

## English

Creates equipment sets and condition-dependent bonuses through an in-game editor.

### Features

- Create, duplicate, and edit sets for equipment slots and Curios slots.
- Activate tiered rewards using equipped piece counts, item variants, NBT, and combined conditions.
- Configure attributes, potion effects, damage, immunities, and commands.
- Support eligible non-player entities and automatically generate set tooltips.

### Usage

Press **F6** to open the KineticArmory set editor. The server determines set activation; changing shared set definitions requires administrator permission.

### Requirements

Required: Forge 47.4.2+, KineticCore 26.9.20+, Curios 5.10.0+. Optional: KubeJS 2001.6.5+.
