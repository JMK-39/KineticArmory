# KineticArmory

## English

KineticArmory turns existing equipment into configurable sets with bonuses triggered by worn pieces, conditions, and combat events.

- Visual set, equipment-variant, and condition editors.
- Attributes, potion effects, damage rules, flight, and commands.
- Curios equipment, configurable tooltips, and optional KubeJS events.

Supports Minecraft **1.20.1 / Forge 47.4.2+** with **Java 17**, **1.21.1 / NeoForge 21.1+** (validated with 21.1.252) with **Java 21**, and **26.1.2 / NeoForge 26.1.2.0+** (validated with 26.1.2.112) with **Java 25**. Requires **KineticCore 26.10.7+ on Forge 1.20.1 (26.10.5+ on NeoForge)** matching the Minecraft/loader. Install required mods on the server and connecting clients.

Required: Curios 5.10+ on Forge 1.20.1, 9.x on NeoForge 1.21.1, or 15+ on NeoForge 26.1.2. Optional: KubeJS 2001.6.5+ on Forge 1.20.1 or 2101.x on NeoForge 1.21.1 (the KubeJS build for 26.1 does not start on 26.1.2 yet).

## 简体中文

KineticArmory 将已有装备组成可配置套装，让加成随穿戴件数、条件和战斗事件变化。

- 可视化套装、装备变种与条件编辑。
- 属性、药水效果、伤害规则、飞行与命令加成。
- Curios 装备、可配置提示及可选 KubeJS 事件。

支持 Minecraft **1.20.1 / Forge 47.4.2+**（**Java 17**）、**1.21.1 / NeoForge 21.1+**（验证使用 21.1.252，**Java 21**），以及 **26.1.2 / NeoForge 26.1.2.0+**（验证使用 26.1.2.112，**Java 25**）；必需与 Minecraft、加载器匹配的 **KineticCore 26.10.7+（Forge 1.20.1；NeoForge 为 26.10.5+）**。服务端与连接的客户端均安装必需模组。

必需：Forge 1.20.1 使用 Curios 5.10+，NeoForge 1.21.1 使用 Curios 9.x，NeoForge 26.1.2 使用 Curios 15+。可选：Forge 1.20.1 使用 KubeJS 2001.6.5+，NeoForge 1.21.1 使用 2101.x（KubeJS 的 26.1 版本目前无法在 26.1.2 上启动）。
