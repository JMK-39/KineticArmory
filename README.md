# KineticArmory

## English

KineticArmory turns existing equipment into configurable sets with bonuses triggered by worn pieces, conditions, and combat events.

- Visual set, equipment-variant, and condition editors.
- Attributes, potion effects, damage rules, flight, and commands.
- Curios equipment, configurable tooltips, and optional KubeJS events.

Supports Minecraft **1.20.1 / Forge 47.4.2+** and **1.21.1 / NeoForge 21.1+** (validated with 21.1.252). Requires **Java 21** and **KineticCore 26.10.3+** matching the Minecraft/loader. Install required mods on the server and connecting clients. **26.1.2 is reserved and disabled, not supported.**

Required: Curios 5.10+ on Forge or 9.x on NeoForge. Optional: KubeJS 2001.6.5+ on Forge or 2101.x on NeoForge.

## 简体中文

KineticArmory 将已有装备组成可配置套装，让加成随穿戴件数、条件和战斗事件变化。

- 可视化套装、装备变种与条件编辑。
- 属性、药水效果、伤害规则、飞行与命令加成。
- Curios 装备、可配置提示及可选 KubeJS 事件。

支持 Minecraft **1.20.1 / Forge 47.4.2+** 与 **1.21.1 / NeoForge 21.1+**（验证使用 21.1.252），必需 **Java 21** 和与 Minecraft、加载器匹配的 **KineticCore 26.10.3+**。服务端与连接的客户端均安装必需模组。**26.1.2 仅预留、未启用，不代表支持。**

必需：Forge 使用 Curios 5.10+，NeoForge 使用 Curios 9.x。可选：Forge 使用 KubeJS 2001.6.5+，NeoForge 使用 2101.x。
